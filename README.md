## 🚀 Instalación en 1 minuto

### Opción A: En Claude Code (Recomendado)
Abre tu terminal y ejecuta este comando para instalarlo globalmente:

```bash
git clone https://github.com/supusvq/supuinsta-instagram-skills.git ~/.claude/skills/supuinsta
```
*¡Listo! La próxima vez que abras Claude Code ya tendrás todas las habilidades cargadas automáticamente.*

### Opción B: En Antigravity / Cursor / Windsurf
Copia la carpeta `skills/` dentro de tu configuración de skills o úsalo directamente abriendo este repositorio en tu editor.

## 🪄 ¿Cómo se usa? (Modo para principiantes)

No necesitas aprender comandos raros. La herramienta incluye un **Asistente Guiado Inteligente**.

Solo dile a tu agente de IA:
> **«Ayúdame a crear un post para Instagram»**  
> o  
> **«Quiero hacer un Reel sobre mi nuevo servicio»**

El agente activará el **Modo Guiado** y te hará preguntas muy sencillas con opciones numeradas:

```text
¿Qué tipo de contenido quieres publicar hoy?
[1] Un Reel corto (15-30s) para llegar a gente nueva.
[2] Un Carrusel explicativo para que la gente lo guarde.
[3] Un Post con imagen para contar una historia o caso real.

👉 Responde solo con el número:
```

Tú solo respondes `1`, `2` o `3`, y el agente se encarga de todo el trabajo técnico y creativo.

## 🔒 Seguridad y Privacidad Garantizada

Este proyecto ha sido auditado para garantizar que es 100% seguro para ti y para tu comunidad:

- ✅ **100% Local:** Todo se ejecuta en tu máquina o en tu sesión de IA habitual.
- ✅ **Sin APIs de pago obligatorias:** Funciona en modo manual sin necesidad de registrarte en ningún servicio externo ni poner tarjetas de crédito.
- ✅ **Cero filtración de datos:** Incluye un `.gitignore` blindado para que tus borradores, ideas y configuraciones privadas nunca se suban a la nube.
- ✅ **Tests de seguridad integrados:** Puedes verificar la integridad del código en cualquier momento ejecutando:
  ```bash
  python3 scripts/selftest.py
  python3 scripts/check_no_secrets.py
  ```

## ⚙️ Opciones avanzadas (Para Power Users)

Si además de redactar quieres automatizar la publicación o conexión con herramientas:
- **Tier 0 (Por defecto):** Genera tarjetas en Markdown limpias para copiar y pegar directamente en Instagram o tu programador habitual (Metricool, Buffer, Later).
- **Tier 1 (API Publora / Meta Graph):** Configura `PUBLORA_API_KEY` en tu `.env` si deseas programar publicaciones automáticamente desde la terminal.
- **Tier 2 (Script personalizado):** Conecta tu propio webhook o script mediante `INSTAGRAM_SKILLS_CUSTOM_POSTER`.
