# Instagram Marketing Skills (2026 Edition)

An agentic marketing bundle of 12 skills designed for Instagram content strategy, production, and distribution across Claude Code, Codex, and Antigravity.

## The 12 Skills

| Skill | Focus | Primary Metric |
|---|---|---|
| `instagram-post-writer` | Captions for Photos, Reels, and Carousels | Saves & SEO Indexing |
| `instagram-reel-scripter` | Multi-column 9:16 Video Scripts (Audio, Visual, Text) | Watch Time & Loops |
| `instagram-carousel-builder` | 4:5 Slide-by-slide Storyboard Generation | Saves & Swipe Completion |
| `instagram-story-strategist` | 24h Daily Story Sequences & Polls | DM Conversation Triggers |
| `instagram-comment-drafter` | Strategic comments on target niche accounts | Profile Visits |
| `instagram-reply-handler` | Comment replies and moving conversations to DMs | Comment Doubling & Sales |
| `instagram-humanizer` | Anti-AI tone filter, emoji cleanup & audit | Audience Trust |
| `instagram-hook-extractor` | Reverse engineering viral Reels/Carousels | Hook Innovation |
| `instagram-content-planner` | Strategic weekly/monthly content calendar | Reach & Pipeline Balance |
| `instagram-profile-optimizer` | Bio SEO, Highlights, and Pinned Posts | Visitor-to-Follower Conversion |
| `instagram-repurposer` | LinkedIn/X/Blog content -> Instagram native assets | Production Efficiency |
| `instagram-interviewer` | Extracts personal anecdotes into the Creator Story Bank | Authenticity & Receipts |

## Architecture

- **Tier 0:** Manual (Copy-paste ready markdown cards, zero setup).
- **Tier 1:** Publora API (`PUBLORA_API_KEY` + `INSTAGRAM_PLATFORM_ID`).
- **Tier 2:** Custom poster script (`INSTAGRAM_SKILLS_CUSTOM_POSTER`).
